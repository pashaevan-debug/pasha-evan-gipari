1. Deskripsi Program
Program Adventure Camp merupakan aplikasi sederhana berbasis bahasa pemrograman C yang digunakan untuk mengelola penyewaan peralatan berkemah. Program ini memungkinkan pengguna melihat daftar peralatan, melakukan penyewaan, menghitung biaya sewa secara otomatis, mendapatkan diskon berdasarkan lama penyewaan, mencetak struk, dan melihat riwayat transaksi.

Program ini menggunakan konsep dasar pemrograman C, seperti variabel, array, percabangan, perulangan, fungsi, serta pengolahan data menggunakan input dan output.
2. Tujuan Program
Tujuan pembuatan program ini adalah:
1. Mempermudah proses penyewaan peralatan berkemah.
2. Menampilkan daftar peralatan beserta harga sewanya.
3. Menghitung biaya penyewaan secara otomatis.
4. Memberikan diskon berdasarkan lama penyewaan.
5. Menyimpan dan menampilkan riwayat transaksi.
6. Menghitung total pendapatan dari seluruh transaksi.
